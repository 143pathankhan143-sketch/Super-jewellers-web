# Product photos

Yahan asli jewellery ki photos rakho. Ek photo = ek product.

## Rules

- **Format:** JPG ya WebP (PNG sirf transparency chahiye to)
- **Size:** 300 KB se kam — 1200×1200 px kaafi hai, 3000 px ki zaroorat nahi
- **Naam:** chhote letters, hyphen, koi space nahi
  - ✅ `minilacha-916.jpg`
  - ❌ `IMG_20261114_1 (2).jpg`
- **Content:** wahi piece jo dukan mein actually available ho
- **Background:** plain / dukan ka display — wallpaper ya doosri site se photo nahi

## Photo kaise laayein (best to worst)

1. **Dukan ki original photos** — phone gallery se seedha. Sabse best: full resolution, koi compression nahi
2. **Instagram se save** — phone par post kholo → ⋯ menu → Save / screenshot. Instagram quality compress karta hai
3. **Reels se** — Reels video hote hain, unse photo nahi milti. Dukan se original maango
